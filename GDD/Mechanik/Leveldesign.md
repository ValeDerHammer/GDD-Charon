# Beginn: Erhalt der Seele

- Kleine Blender-Szene, grey-tinged, Charon in einem Boot im Wasser, viel Stein, düster mit einem Steg und einer Statue/Geformtem Steinfelsen (menschenähnlich), von der die Seele zum Spieler fliegt, wenn er interagiert (Pro Seele ein Steg + 1 Statue)
- Wahl der Obolus-Coins nach dem Tutorial

# Raumaufteilung: Kampf vs. Pause

- **Pauseraum/Checkpoint:** Lebensbrunnen
- ==🔴Ursprünglich 3 Teile eines Levels: Swamp, kompletter Dungeon, Endboss==

## Bonfire/Lebensbrunnen

- **Interaktion**: Rasten
	- Heilt Charakter
	- Füllt Heiltränke auf
	- besiegte Gegner spawnen wieder (???)
	- Checkpoint für Respawns nach Tod: Speichert Spielstand
	
	- Level Up von Primären und Sekundären Fähigkeiten


----
- Anmiation: Seele kreist um Brunnen, wenn Spieler Raum betritt (visueller Hinweis)
- Reicht nicht ein Leuchten?

- Interagieren: Seele zündet Bonfire an
	- dann kommen 3 Wellen an Gegner und am ende ein Miniboss
		- wenn das Bonfire in der Zeit Kaputt geht is der Run vorbei
- ==🔴man kann nur begrenzte Anzahl an Bonfires Aktivieren==
